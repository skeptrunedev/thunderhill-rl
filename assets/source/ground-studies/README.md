# Ground treatment experiments

`flattened-field-v1.png` is an original image generated with the built in
imagegen tool. The supplied frame 40 was appearance guidance only. The exact
prompt is stored alongside the source. No video frame is redistributed.
The result is 1254 by 1254 pixels despite the requested 2048 size.
Runtime color mipmaps are filtered in linear light by the existing bake tool.
This is not a measured scan; texture scale and inferred relief are estimates.

The standalone generated treatment bypasses the production aerial and procedural
color layers. It is an experiment, not a production replacement.

`sparse-field-v1.png` is original artwork made with built in image generation
using the exact sibling prompt. The generator received text only. It depicts
sparse cut fragments over exposed earth, not a measured or extracted material.
Actual dimensions are 1254 square, rather than the requested 2048. Source SHA256:
`568c9e4b236a077f22ca98c10c3ead89681b4edda0a3c66ca64bc0478df01e7f`.
The runtime resource has ten color mip levels filtered in linear light.
Four metre scale, material weights, roughness and relief are artistic estimates.
